# Image Archive & Human vs AI Detection

An interactive 3D semi-circle circular gallery built with React, Vite, Tailwind CSS, and OGL WebGL.

## Features
- **3D Circular Carousel**: Continuous 360-degree arched gallery with natural perspective and touch/drag controls.
- **Two-Stage Card Interaction**:
  - **First Click**: Zooms the selected card smoothly towards the camera into an elevated close-up view.
  - **Second Click**: Flips the card 180° around the Y-axis with interactive 3D mouse tilt.
- **Minimal Card Back**: Sleek `#27272a` card face showing Title on top, Image Type on bottom-left, and Origin (AI Generated vs Human Made) on bottom-right.
- **15-Round Perception Experiment**: Full interactive test testing human perception vs generative AI.

## Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Start the development server
```bash
npm run dev
```

### 3. Build for production
```bash
npm run build
```
